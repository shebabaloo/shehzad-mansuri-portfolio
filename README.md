# The Living Score

Production-oriented desktop foundation for Shehzad Mansuri's personal website.

## Local development

```sh
npm install
npm run dev
```

Open `http://127.0.0.1:4173`.

## Verification

```sh
npm run lint
npm run build
```

## Current experience

- React 19, TypeScript, Vite, Tailwind CSS, and GSAP ScrollTrigger
- Abstract stellar field gathering into a five-arm score galaxy
- Delayed secondary folio and one reversible score-to-staff sequence
- Staff resolves into a fixed, keyboard-accessible right-edge score rail
- Warm editorial first movement with semantic HTML and reduced-motion fallback
- Career measures, connected systems voices, honest early-stage variations, personal
  ensemble movements, and a closing coda

Desktop is the active design target. Mobile remains intentionally deferred while the
opening interaction is iterated. This site is not approved for publication or
deployment. Quantified professional claims remain excluded until reconfirmed.
